#  Minimalist Accessories Store

https://accessories-store-iota.vercel.app/

A modern, high-performance E-Commerce web application built with **React.js**, **TypeScript**, and **Tailwind CSS v4**.

## 🚀 Tech Stack & Architecture

- **Frontend:** React.js, TypeScript, Vite
- **Styling:** Tailwind CSS v4, Lucide Icons, clsx, tailwind-merge
- **State Management:** React Context API + `useReducer` with `localStorage` persistence
- **Routing:** React Router DOM (Multi-page App)
- **Patterns:** Feature-based folder structure, Custom Hooks, Atomic UI Components, Debounce Search, Toast Notification System

## ✨ Key Features

- **Dynamic Shop & Catalog:** Category filtering, multi-parameter sorting, and live product search with debouncing (`useDebounce`).
- **Interactive Shopping Cart:** Slide-over Cart Drawer, quantity adjustment, persistent storage, and dynamic free-shipping progress tracker.
- **Product Details:** Single product view with dynamic image galleries, feature highlights, and related product recommendations.
- **Toast Notifications:** Smooth visual feedback stack on cart actions.
- **Responsive Design:** Mobile-first, elegant neutral design inspired by modern luxury boutiques.
